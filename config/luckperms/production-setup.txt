# MineSpace — LuckPerms produção
# Aplicar na consola (ou importar por blocos). Sem wildcards (*).
# Ordem: criar grupos → parents → permissões → negar perigosas no default
#
# Pré-requisito: OBM-* recompilados com permissões novas (obm.smp.money.pay, etc.)

# =============================================================================
# 1. GRUPOS E HIERARQUIA
# =============================================================================

lp creategroup default
lp creategroup vip
lp creategroup mvp
lp creategroup builder
lp creategroup helper
lp creategroup mod
lp creategroup admin
lp creategroup owner

lp group vip parent add default
lp group mvp parent add vip
lp group builder parent add default
lp group helper parent add mvp
lp group mod parent add helper
lp group admin parent add mod
lp group owner parent add admin
