# MineSpace — Recomendações Gerais (Auditoria Produção)
# Gerado: 2026-06-02 | Score global: 74/100

================================================================================
PRIORIDADE P0 — ANTES DE LANÇAMENTO PÚBLICO (100+ jogadores)
================================================================================

[ECONOMIA] Unificar escritor de smp_balance
  - Problema: EconomyService, PlayerCacheService e EconomyBridge escrevem a mesma chave com locks diferentes.
  - Acção: PlayerCacheService como source-of-truth quando activo; SMP EconomyService delega.
  - Ficheiros: EconomyService.java, PlayerCacheService.java, EconomyBridge.java

[ECONOMIA] Atomicidade PlayerData + sync async
  - Problema: dirty/pendingCoinDelta podem perder-se durante savePlayerFullSync assíncrono.
  - Acção: synchronized ou AtomicInteger; snapshot-and-clear atómico antes do HTTP POST.
  - Ficheiros: PlayerData.java, PlayerCacheSyncTask.java

[LOJA] Promo atómica no checkout
  - Problema: desconto aplicado no checkout, claim só no webhook → race em promo limitada.
  - Acção: reservar/claim promo na transacção createOrder; rejeitar fulfill se claim falhar.
  - Ficheiros: routes/store.js, db/promoRepository.js, routes/stripeWebhook.js

[SEGURANÇA WEB] Headers HTTP + CSP
  - Problema: sem helmet, sem CSP, sem X-Frame-Options — clickjacking + XSS sem defesa em profundidade.
  - Acção: npm helmet, CSP restritiva, HSTS em produção.
  - Ficheiro: server.js

[SEGURANÇA WEB] Username só após confirm link
  - Problema: link/start grava minecraft_username antes de provar posse via /link in-game.
  - Acção: persistir username apenas em web/link/confirm com UUID validado.
  - Ficheiro: routes/webAuth.js
